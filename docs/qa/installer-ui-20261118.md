# 개발자 설치 화면 정리

2026-11-18 KST. 구현 commit `43b2472ef36e99c11b685bdc8a8111ebb5d66c07`.

## 변경

- 큰 제목과 4단계 사이드바를 서비스 등록 폼·LLM 연결 정보의 두 영역으로 교체했습니다. 모바일에서는 세로로 배치합니다.
- 서비스를 저장하면 중앙 주소·서비스 ID·사이트 주소와 LLM 복사 버튼을 바로 보여줍니다. 복사 내용은 공개 npm 안내 링크와 저장된 연결 정보이며 비밀키를 포함하지 않습니다. 저장하지 않은 수정이 있으면 복사를 차단합니다.
- 이용 대상은 `승인된 회원`, `지정한 맹`, `최고 관리자`로 줄였습니다. 각각의 의미는 선택 아래에서 설명합니다. 신규 등록에서는 대상을 명시적으로 선택하며 기존 서비스 정책은 그대로 읽습니다.
- 개발자는 새 서비스 등록 시 중앙 명부의 맹을 선택합니다. 목록이 비면 관리자에게 등록을 요청하도록 안내합니다. 새 맹 등록과 기존 서비스 정책 변경은 기존대로 중앙 관리자 권한이며, 개발자 화면에는 잠금 이유를 표시합니다.
- Workers·Pages·기타 서버의 수동 설치, 검증·업데이트·복구 안내는 `직접 설치 · 고급 설정`에 유지했습니다. 복사되는 명령은 실제 줄바꿈을 사용합니다.

서버 API·권한 판정·명부·SDK 소스는 변경하지 않았습니다. DB 마이그레이션과 npm 재게시는 하지 않았습니다.

## 로컬 검증

타입 검사, 브라우저에 삽입되는 JavaScript 문법 검사, Wrangler dry-run 빌드와 기존 정책 테스트 **11/11**을 통과했습니다. 테스트는 `tests/platform.test.ts`, `tests/common-membership.test.ts`이며 개발자 권한·서비스 소유권·정책 완화 차단을 포함합니다.

브라우저는 합성 사용자 세션, 실제 Hono 개발자 API와 Miniflare D1을 연결한 로컬 서버에서 확인했습니다. 네트워크 실패·저장 거절 화면만 별도의 오류 응답으로 재현했습니다.

1. 새 개발자가 등록된 맹을 선택해 서비스를 등록합니다.
2. 등록 후 기존 서비스 정책은 잠금 안내와 함께 표시됩니다.
3. 클립보드에 공개 안내 링크·버전·서비스 ID·중앙 주소·사이트 주소·정책이 저장된 값으로 복사됩니다.
4. 미저장 수정이 있으면 복사를 막습니다.
5. Pages 빌드 폴더·브랜치·프로젝트 생성 명령과 기타 서버 어댑터를 유지합니다.
6. 맹이 없는 상태에서 `지정한 맹`을 선택하면 안내하고, 맹 없이 등록하거나 다른 정책으로 자동 완화하지 않습니다.
7. 불러오기 실패 후 재시도로 복구하며, 저장 실패 후 입력값을 보존합니다.
8. 최고 관리자는 기존 정책을 편집할 수 있고 개발자는 편집할 수 없습니다.
9. 모바일 모드와 긴 URL에서 가로 넘침이 없습니다. 요청한 모바일 크기는390×844, 브라우저 확대를 반영한 실제 CSS 폭은355px이었습니다.

## 임시 서버 반영

[실제 설치 화면](https://ak-auth-trial-20261114.nakwol.workers.dev/developer/install)에 반영했습니다. Worker version은 `a1d51341-d156-4fc5-a8d3-77b0cc80b11d`입니다.

배포 전후 DB 연결·Firebase 변수의 값·compatibility 설정을 대조해 동일함을 확인했습니다. 다른 검증 Worker와 시험 소비 사이트는 코드 식별값과 수정 시각이 동일합니다. 운영 서버는 배포하지 않았습니다.

원격 브라우저에서는 새 화면·정렬된 입력창·첫 화면 안의 등록 버튼과 활성 맹 선택 목록(당시2개)을 확인했습니다. 기존 사용자 탭에 작성 중인 폼이 있어 그 탭은 새로고침하지 않고 새 탭에서 확인했습니다. 실제 시험 DB에 서비스나 맹을 새로 등록하지 않았습니다. 신규 등록·복사·오류 상태 검증은 위 합성 로컬 환경에서 수행했습니다.
