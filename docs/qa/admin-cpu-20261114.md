## 변경 내용

- 관리자 조회는 D1에서 허용된 데이터만 모아 한 번 직렬화하여 Worker에서 수백 개 행을 다시 구성·필터링·직렬화하는 비용을 줄였습니다. 응답 필드, 정렬, 운영자·소속 관리자·개발자 범위는 유지합니다.
- 단일 JSON이 D1의 2MB 값 제한에 걸리면 전체 행을 읽는 호환 경로로 반환합니다. 데이터나 이력을 잘라내지 않습니다. 이 전환은 해당 크기 오류에만 적용하며 다른 DB 오류를 성공으로 숨기지 않습니다. [D1 한도](https://developers.cloudflare.com/d1/platform/limits/)
- 기존 세션 SELECT를 공유하여 Firebase 전용·만료·7일 절대 수명·재인증 조건과 관리자 역할을 한 번에 조회합니다. 인증 방식이나 세션 정책은 바꾸지 않았습니다.
- 미리보기는 입력한 UID만 인덱스로 조회하고 Map으로 비교합니다. 시즌 전체 명부와 사용하지 않는 연결 정보는 가져오지 않습니다.
- 가져오기는 변경 항목만 쓰기 SQL에 전달합니다. JSON UID를 TEXT로 비교하여 기존 고유 인덱스를 사용하고, 연결 계정 변경 대상을 MATERIALIZED CTE로 한 번 정합니다.
- 쓰기 직전 권한·시즌/소속·전체 입력 revision 검사를 같은 원자적 트랜잭션 안에서 유지합니다. 합쳐진 guard도 동일한 조건을 AND로 검사합니다. 변경 없는 가져오기도 권한과 revision을 확인하고 감사 기록을 남깁니다.
- 공개 API·DB 스키마·migration·SDK 실행 코드·프런트 UI 변경 없음.

실제 D1 호출 검증에서 왕복 수는 관리자 조회 **11→2**, 미리보기 **8→2**, 가져오기 **9→3**입니다. 107개 변경 없음 입력의 쓰기 batch는 221행, 연결된 107개 변경의 batch는 1,826행을 읽었습니다. 전체 로그인 요청 수·SDK의 요청 기반 5분 권한 lease와 7일 세션은 그대로입니다.
