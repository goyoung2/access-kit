## 검증 범위

별도 합성 세션으로 실제 원격 HTTP, D1, PKCE 코드 교환 및 기존 소비 사이트 SDK 게이트 **34개 검사**를 통과했다. 실제 200명 명부에서 아직 연결되지 않은 CID 두 개를 잠시 사용했으며 검증 후 모든 임시 연결을 해제했다.

- 명부 CID는 별도 승인 없이 맹원으로 가입한다. 닉네임 불일치도 허용한다.
- 명부 밖 CID는 방문자로 가입하고 맹원 전용 서비스의 인증 코드를 받지 못한다.
- 같은 닉네임·다른 CID의 두 명이 각각 가입된다. 이미 연결한 CID의 두 번째 계정 신청은 409다.
- 일반 계정은 관리자 데이터를 읽지 못하며 가입/권한 응답에 비교 닉네임·불일치 필드가 없다.
- 실제 관리자 브라우저에서도 시험 회원 한 행에 **닉네임 확인 필요** 및 **맹원** 표시를 확인했다.
- 맹원은 중앙 `/me`, 보호 HTML·자산·API에 접근한다. 익명 접근은 모두 401이며 잘못된 방문자 토큰으로 소비자 세션을 만들 수 없다. 로그아웃 후 중앙 토큰은 무효다.
- 시험 계정 4개와 해당 세션·토큰·CID 연결을 정리했다. 창천 200명 명부는 유지했다.

Google 로그인 자체는 위 합성 세션 검사에 포함되지 않는다. 현재 로그인된 실제 Google 계정의 가입 화면을 열었지만 닉네임·CID를 대신 입력하거나 가입을 제출하지 않았다. 사용자가 **직접 가입을 진행**하기로 했으며, 마지막 읽기 전용 조회에서는 직접 가입이 아직 관찰되지 않았다. 직접 가입 및 사용자 브라우저의 최종 입장은 후속 확인 대상이다.

## 변경 경계와 근거

Firebase 변수 값·DB 바인딩·호환성 설정을 배포 전후 대조했다. `access-kit-validation-20261112` 및 `ak-atlas-trial-20261114`의 Worker etag/수정 시각은 바뀌지 않았다. 운영 배포·운영 DB 변경·npm 게시·GitHub push는 수행하지 않았다. 소비 Worker는 재배포하지 않고 중앙 시험 DB의 서비스 정책만 변경했다.
